# Sesi 2026-08-02 (petang, Windows) — Baiki TTS Claude Code & tukar ke suara Osman

## Masalah asal

Selepas restart Claude Code, hook TTS langsung **tidak bersuara** walaupun sebelum ini
dijangka sudah berfungsi. User terpaksa mengingatkan berkali-kali.

## Diagnosis — tiga punca berasingan

Rupanya ada **tiga** masalah bertindih, bukan satu:

### 1. Proses suara dibunuh bersama pokok proses hook

Hook `Stop` memang terpicu (disahkan: fail `claude-speak-text.txt` bertarikh 18:42:19
dengan teks yang betul). Tetapi `speak-hook.ps1` melancarkan pembaca suara guna
`Start-Process`, menjadikannya **anak kepada proses hook**. Sebaik hook tamat,
Claude Code membunuh keseluruhan pokok proses itu — jadi bacaan mati sebelum
sempat berbunyi.

**Penyelesaian:** lancar proses suara melalui WMI supaya ia menjadi anak `WmiPrvSE`,
bukan anak hook:

```powershell
$res = Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{ CommandLine = $cmd }
```

Ada fallback ke `Start-Process` kalau WMI gagal.

### 2. Output audio pergi ke peranti yang salah

Sistem ada dua peranti render aktif. Peranti **default** ialah
`LG TV SSCR2 (3- Intel(R) Display Audio)`, bukan `Speakers (USB Audio and HID)`.
Volume 100%, tidak dibisukan — jadi suara memang keluar sepanjang masa, cuma
dihantar ke TV.

Disahkan guna COM interop `IMMDeviceEnumerator::GetDefaultAudioEndpoint`:

```
DEFAULT=LG TV SSCR2 (3- Intel(R) Display Audio)|VOLUME=100%|MUTED=False
```

**Keputusan user:** kekalkan LG TV sebagai default. Tiada perubahan dibuat pada
tetapan audio sistem.

### 3. Bug `--rate` menyebabkan jatuh ke suara sandaran

`edge-tts --rate -10%` menyebabkan `-10%` disalah anggap sebagai flag
(`error: argument --rate: expected one argument`), jadi Osman gagal dan skrip
jatuh ke Rizwan. User perasan: *"bukan suara osman..suara rizwan ke tu?"*

**Penyelesaian:** guna bentuk `--rate=-10%` sebagai satu token tunggal.

## Pembetulan nota memori yang salah

Nota lama menyatakan **"Osman ialah suara Turki dan tak terpasang"** — itu **salah**.
`ms-MY-OsmanNeural` ialah suara *neural* Melayu Microsoft (Azure/Edge), bukan OneCore.
Sebab itu ia tidak muncul dalam senarai `SpeechSynthesizer::AllVoices`.

Senarai suara Melayu edge-tts yang tersedia:

| Suara | Jantina |
|---|---|
| `ms-MY-OsmanNeural` | Lelaki |
| `ms-MY-YasminNeural` | Perempuan |

## Konfigurasi akhir

**`~/.claude/scripts/speak.ps1`**

- Utama: `ms-MY-OsmanNeural` via `edge-tts` (perlu internet)
- Sandaran: `Microsoft Rizwan` (ms-MY, OneCore/WinRT) — luar talian
- Loudness `+40%` (permintaan user), rate `-10%`
- Main MP3 guna **Windows MCI (winmm)** — sama kaedah dengan `say_osman.ps1`
  milik user; tak perlu apartment STA dan tak buka sebarang UI
- Buang markdown, blok kod, pautan dan emoji sebelum dibaca
- Had 1500 aksara
- Log diagnostik ke `~/.claude/scripts/speak.log`

**`~/.claude/scripts/speak-hook.ps1`**

- Baca `transcript_path` dari stdin JSON, ambil mesej assistant terakhir
- Bunuh bacaan lama guna fail PID
- Lancar `speak.ps1` terpisah melalui WMI

**Pemasangan:** `python -m pip install --upgrade edge-tts` (Python 3.12)

## Pengajaran utama

> Bila hook Claude Code di Windows perlu menjalankan kerja yang hidup lebih lama
> daripada hook itu sendiri, **jangan** guna `Start-Process` sahaja. Proses anak
> akan dibunuh bersama pokok proses hook. Guna `Win32_Process.Create` melalui WMI.

> Bila TTS "senyap" tetapi log kata berjaya — periksa **peranti audio default**
> sebelum menyalahkan skrip.
